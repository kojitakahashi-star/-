# 添付書類コメント管理

チャットで入力されたコメント・議事録を書類に紐づけて記録し、タスクとして管理するための場所です。

## 構成

```
attachments/            コメント対象の添付書類原本
comments/logs/*.md      チャットで受け取ったコメント・議事録(生ログ、日付ごと)
comments/tasks.md       ログから抽出したタスク一覧(対応要否・ステータス管理)
```

## 使い方

1. チャットで書類とコメント(議事録・指摘事項など)を送ってもらう
2. 生ログを `comments/logs/<日付>_<件名>.md` として保存
3. 内容を精査し、対応が必要な項目を `comments/tasks.md` にタスクとして追加
   - 関連する場合は原本(規格書など)の該当箇所も付記する
4. 「タスク一覧出して」→ `comments/tasks.md` を提示
5. 「この項目はどうすればいい?」→ 該当タスクの内容と、原本の該当条項を踏まえて回答
