## 提案の骨子

「木材を売る」提案ではなく、**開発本部の意思決定に乗る形**に寄せている。

- 過去のヒアリングで得た「デザイン性が入口、サステナビリティは後からついてくる」という判断軸に沿い、B（施設木質化）はデザインと賃料の話として提示
- A（樹木活用）は処分費のかかる伐採木を素材に振り替える話として提示し、伐採**前**の情報連携をお願いする形にしている
- 依頼のハードルを「まず情報共有（STEP1）」に置き、初回で受注の判断を求めない
