# 森林認証ナレッジ AIアシスタント

Notion の「森林認証ナレッジベース」をもとに、Claude が出典付きで回答する社内向けWebページです。
Google Apps Script のウェブアプリとして動き、shin-mirai.co.jp の Google アカウントでログインした人だけが使えます。
利用者は Claude のアカウントを持っていなくても使えます。

## 仕組み

```
利用者（ブラウザ）
   │  社内Googleアカウントでログイン
   ▼
Apps Script ウェブアプリ ──1時間ごと──▶ Notion API（ナレッジ記事・指摘事例・テンプレート集を取り込み）
   │                                       ▲
   │ 質問に関連する記事だけを渡す            │「質問箱に送る」で質問箱に登録
   ▼                                       │
Claude API ─────────── 回答（出典リンク付き）
```

- APIキーと Notion トークンはスクリプトプロパティに保管し、利用者には見えません。
- 取り込んだナレッジは、デプロイした人の Google ドライブに `forest-kb-assistant-cache.json` として保存されます。
- 利用ログ（日時・利用者・質問・質問箱に送ったか）はスプレッドシート `森林認証AIアシスタント_利用ログ` に記録され、
  新人の自己解決率（KPI）の集計に使えます。

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | Notion の取り込み、関連記事の検索、Claude の呼び出し、質問箱への登録 |
| `Index.html` | チャット画面 |
| `appsscript.json` | 公開範囲（社内ドメインのみ）と権限の設定 |

## セットアップ

手順の詳細（設定する値を含む）は Notion の「森林認証ナレッジベース」配下の
「AIアシスタント セットアップ手順」ページにあります。概要は次のとおりです。

1. Notion でインテグレーションを作成し、「森林認証ナレッジベース」ページに接続する
2. Claude API キーを発行する
3. Apps Script プロジェクトを作成し、3つのファイルを貼り付ける
4. スクリプトプロパティ `ANTHROPIC_API_KEY` `CLAUDE_MODEL` `NOTION_TOKEN` を設定する
5. `setup` 関数を1回実行する（1時間ごとの取り込みが登録される）
6. 「デプロイ」→「ウェブアプリ」→ 実行ユーザー「自分」、アクセス「shin-mirai.co.jp 内の全員」でデプロイする
