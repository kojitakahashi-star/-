# 森林認証(FSC / SGEC / PEFC) 不明点 解答集

FSC・SGEC・PEFC の認証で不明点が出たときに、規格原文の条項番号を根拠に回答するための資料集です。

## 使い方

1. 質問のキーワード(例:「クレジット」「外注」「重大不適合」「マルチサイト」)で該当ファイルを検索する。
2. 回答には必ず「根拠：条項番号」を添える。
3. 本資料に載っていない論点は「別規格(本資料に未収録)」と明示し、該当規格名を示す。推測で回答しない。

## 注意事項

- FSC 日本語版は FSC 国際本部の公式訳ではなく、英語原文が優先する。
- SGEC 規格の公式言語は日本語。ただし PEFC 規格の和訳は仮訳であり、解釈に疑義がある場合は PEFC 規格(英文)が優先する。
- **未収録の主な関連規格**(必要に応じて原本を追加入手すること)
  - SGEC 規準文書 4「森林及び森林外樹木産品の SGEC-COC 要求事項」/ PEFC ST 2002:2020(取得組織向け COC 要求事項本体)
  - SGEC 規準文書 6 / PEFC ST 2001「商標使用規則」
  - FSC-STD-50-001(FSC 商標使用)、FSC-STD-40-005(管理木材の調達)、FSC-STD-40-003(マルチサイト CoC 認証の旧規格)など
- 規格は改訂されるため、回答前に各スキームの公式サイトで最新版・移行期限を確認すること。
