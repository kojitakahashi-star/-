# 企業ディープリサーチ・データベース

指定した企業をディープリサーチし、結果を SQLite データベース (`db/companies.db`) に保管する仕組みです。

## 保管している項目

- 会社名
- 拠点数、本社所在地
- 業種
- 事業内容
- 扱っている商品
- 扱っている加工
- 特徴
- 強み

不燃工場・メーカーについては、以下の項目も追加で保管する(該当情報が無い企業では省略可)。

- 扱っている不燃(不燃材料・準不燃材料・難燃材料等の区分)
- 対応樹種
- 不燃商品と塗料の組み合わせ
- 大臣認定をとっている不燃木材と下地材の組み合わせ
- 扱っている不燃商品・不燃塗料の名称(ブランド名・商品名)

## 構成

```
db/schema.sql              テーブル定義
db/companies.db            SQLiteデータベース本体
data/researched/*.json      企業ごとのリサーチ結果(JSON)
scripts/init_db.py          DB初期化
scripts/add_company.py      リサーチ結果JSONをDBに登録(UPSERT)
scripts/query_company.py    DBの内容を一覧・詳細表示
```

## 使い方

### 1. DBの初期化(初回のみ)

```bash
python3 scripts/init_db.py
```

### 2. 新しい企業をリサーチしてJSONを作成

`data/researched/<会社名>.json` を以下の形式で作成する。

```json
{
  "company_name": "会社名",
  "headquarters_location": "本社所在地",
  "num_locations": 7,
  "locations_detail": "拠点の内訳",
  "industry": "業種",
  "business_description": "事業内容",
  "products": "扱っている商品",
  "processing": "扱っている加工",
  "fireproof_materials": "扱っている不燃(不燃工場・メーカーのみ)",
  "wood_species": "対応樹種(不燃工場・メーカーのみ)",
  "fireproof_paint_combination": "不燃商品と塗料の組み合わせ(不燃工場・メーカーのみ)",
  "certified_substrate_combination": "大臣認定をとっている不燃木材と下地材の組み合わせ(不燃工場・メーカーのみ)",
  "fireproof_product_paint_names": "扱っている不燃商品・不燃塗料の名称(不燃工場・メーカーのみ)",
  "features": "特徴",
  "strengths": "強み",
  "source_urls": "参照元URL(改行区切り)",
  "researched_at": "YYYY-MM-DD"
}
```

不燃項目が対象外の企業では、上記4項目を省略するかnullのままでよい。

### 3. DBへ登録

```bash
python3 scripts/add_company.py data/researched/<会社名>.json
```

### 4. 登録内容の確認

```bash
python3 scripts/query_company.py                  # 一覧表示
python3 scripts/query_company.py "<会社名>"        # 詳細表示
```
