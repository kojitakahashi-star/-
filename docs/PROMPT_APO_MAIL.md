# 新しいチャットで使うプロンプト（アポ打診メールの下書き作成）

このリポジトリで新しいセッションを開いたときに、そのまま貼って使う文面。
リストの部分だけ差し替える。**送信はせず下書きまで**が前提。

---

## A. 短い版（このリポジトリで使う。ふだんはこれでOK）

```
/apo-mail

下記の担当者に新規アポ打診メールを送りたい。会社ごとにリサーチしてから、担当者ごとに1通ずつGmailの下書きを作って。

会社名	担当者名	メールアドレス	部署	役職
株式会社◯◯	山田 太郎	yamada@example.co.jp	設計部	課長
△△デザイン株式会社	佐藤 花子	sato@example.jp

進め方:
1. 各社の公開情報をリサーチして data/prospects に保存＋DB登録
2. 会社ごとのブリーフ（業種・事業内容・木材との接点・メールの切り口）を表で提示 → ここで一度止めて確認
3. OKが出たら本文を作って、担当者ごとにGmailの下書きを作成（送信はしない）
```

`/apo-mail` が使えない場合は「アポメール作って」でも同じスキルが動く。

## B. フル版（スキルが読み込まれない環境／他の人に渡すとき）

```
このリポジトリの仕組みを使って、新規アポ打診メールの下書きを作ってください。
手順は .claude/skills/apo-mail/SKILL.md と docs/COLD_OUTREACH.md にあります。

【送付先リスト】（会社名／担当者名／メールアドレス／部署／役職）
株式会社◯◯	山田 太郎	yamada@example.co.jp	設計部	課長
△△デザイン株式会社	佐藤 花子	sato@example.jp

【やってほしいこと】
1. 上のリストを data/outreach/cold_targets.tsv に書き出し、
   python3 scripts/cold_import.py data/outreach/cold_targets.tsv を実行（担当者ごとに1通）
2. python3 scripts/prospect_brief.py --missing で未リサーチの会社を確認し、
   1社ずつ公開情報を調べて data/prospects/<会社名>.json に保存、
   python3 scripts/add_prospect.py で prospects テーブルに登録
   - 業種／所在地／事業内容／手がける領域／特徴・強み／木材との接点／メールの切り口／
     注意(未確認事項)／参照元URL／調査日 を埋める
   - 木材・木質化の実績が見つからなければ「公開情報では確認できず」と書く（あることにしない）
   - 受賞・取引先・グループ関係など裏が取れないものは caution に残す
3. 会社ごとのブリーフを表で提示して、いったん止めて確認を取る
   （業種／事業内容／木材との接点／メールで使う切り口）
4. 確認後、cold_campaign.json の talked_about（本文2段落目）を会社ごとに1〜2文で書き、
   python3 scripts/render_mails.py --campaign data/outreach/cold_campaign.json \
     --outdir out/cold_mails --json out/cold_mails.json
   で「要記入 0件」になるまで仕上げる
5. out/cold_mails.json の to / cc / subject / body をそのまま Gmail の下書きにする
   （本文は1文字も変えない。作成後 gmail_draft_id と status を記録）
6. 宛先・件名の一覧と代表1通の本文を提示し、判断に迷った点を明示。最後にコミットしてプッシュ

【守ってほしいこと】
- 送信・送信予約はしない（下書きまで）
- cc に marketing@shin-mirai.co.jp を必ず入れる（宛名ブロックには出さない）
- 署名・日程調整リンク（リンク1・リンク2）・インパクトレポートは既定値をそのまま使う
- 同じ会社に複数名いる場合は担当者ごとに別便。1通にまとめたいときは指示する
```

## C. 名刺交換した相手へのフォローの場合

```
/apo-mail

イベントで名刺交換した人にフォローメールを送りたい。名刺CSV（Eight書き出し、Shift-JISのままでOK）を添付します。
イベント名は「◯◯」、開催日は◯月◯日。

進め方:
1. CSVを取り込み、会社＋部署ごとにまとめて to / cc を役職順で振り分け
2. グループ一覧を提示 → まとめ方や to/cc を選択式で確認
3. 各社の切り口（当日話した内容 or 調べた内容）を決めて本文を作成
4. 確認後、Gmailの下書きを作成（送信はしない）
```

---

## リストの書き方（共通）

- 1行1名。区切りはタブ / カンマどちらでも可
- 最低3列（会社名・氏名・メール）。部署・役職は任意
- 氏名は「姓 名」の間に空白を入れる（件名の「【山田様】」に使う）
- Salesforce のエクスポートCSVをそのまま貼ってもよい（会社名・氏名・メールを拾う）
- 6列目に「ひとこと」を自分で書いておくと、その文がそのまま本文2段落目に入る（リサーチ結果より優先）
