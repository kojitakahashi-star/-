# プレゼン資料

## 八王子_森林地域循環_企業版ふるさと納税.pptx

八王子市の森林・木材を活用した地域内循環づくりの検討資料（全32枚、16:9）。
「森を守るためにお金を使う」から「森から価値を生み、その価値で森を守る」への
転換を、企業版ふるさと納税を初期投資として使う事業案として整理したもの。

構成:

1. 提案の核・本日の流れ（p.1-3）
2. 第1章 八王子市の森林の課題（p.4-9）
3. 第2章 これまでの取り組み（p.10-12）
4. 第3章 それでも残る課題（p.13-16）
5. 第4章 企業版ふるさと納税で何を変えるか（p.17-31）
6. 注記・主な参照資料（p.32）

全ページにスピーカーノート付き。

### 再生成

```bash
npm install pptxgenjs
node build_hachioji_deck.js 八王子_森林地域循環_企業版ふるさと納税.pptx
```

`build_hachioji_deck.js` がレイアウト・文言をすべて保持しているため、
修正はスクリプト側を編集して再生成するのが確実。

### 注意

数値・事実関係（2026年度予算額、婚姻件数、各事業の実施状況など）は
公表資料に基づく整理であり、提案化の前に最新資料での最終確認が必要。
企業版ふるさと納税の制度要件は内閣府ポータルサイト等で確認すること。
