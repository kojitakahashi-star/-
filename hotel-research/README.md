# 商店建築 ホテル設計者データベース 2011–2026

『商店建築』に掲載されたホテル・旅館・宿泊施設と、その設計会社・代表者・木材/地域材利用実績を調査し、
株式会社森未来の営業・PR・アライアンス開拓に使うためのデータベース。

## 成果物

- `商店建築_ホテル設計者データベース_2011-2026.xlsx`
  - `方法論・注記`: 調査方法・確認できた件数・評価基準・調査環境の制約
  - `OUTPUT1_全件リスト`: 確認できたホテル・旅館72件、35項目
  - `OUTPUT2_営業優先順位`: S→A→B→Cの営業優先度順リスト
  - `OUTPUT3_設計会社ランキング`: 商店建築掲載ホテル数が多い設計会社の集計
  - `OUTPUT4_TOP20`: 森未来との事業シナジー基準で選定したアプローチ優先20社と営業戦略
  - `除外候補(要再確認)`: 施設名自体が確認できず本体リストから除外した候補

## 確認できた件数

72件(目標100〜300件に対し、下記の制約により72件にとどまった。無理な水増しは行っていない)

## 重要な制約(必読)

本調査は自動化されたリサーチエージェントがWeb検索のみで実施した。実行環境の制約上、

- **WebFetch(Webページ本文を直接読む機能)が shotenkenchiku.com を含むほぼ全ドメインで使用不可**だった
- **WebSearchの呼び出し回数に上限**があり、複数回、上限到達により調査を打ち切っている

このため、商店建築公式サイトの「年間総目次」「月刊総目次」を直接閲覧して号ごとの掲載物件を網羅的に確認する、
という本来最も確実な調査手順が実行できていない。掲載号・ページ番号・木材利用実績等の一次情報が
「不明」のままの項目が多く残っている。詳細はワークブック内「方法論・注記」シートを参照。

## 追加調査の推奨

- WebFetchが利用可能な環境、またはshotenkenchiku.com公式の年間総目次データ(PDF等)の提供があれば、
  掲載号・ページ・設計者クレジットの網羅的確認が可能になり、件数・精度とも大幅な向上が見込める。
- 国立国会図書館等でのバックナンバー現物確認も有効。

## 構成

```
商店建築_ホテル設計者データベース_2011-2026.xlsx   最終成果物(Excelワークブック)
build_workbook.py                                  data/の情報からワークブックを再生成するスクリプト
data/hotels_data.py                                ホテル一次データ(Phase1-4調査結果)
data/design_firms_data.py                          設計会社プロフィール(Phase5調査結果)
data/hotels_final.json                             OUTPUT1相当のスコアリング済みJSON
data/design_firms_rollup.json                       OUTPUT3相当の設計会社集計JSON
```

## 再生成方法

```bash
pip install openpyxl   # 未インストールの場合
python3 build_workbook.py
```

`data/hotels_data.py` に新規物件を追記し、`data/design_firms_data.py` に設計会社情報を追記すれば、
スコアリング(地域材親和性・営業優先度)とTOP20選定は自動的に再計算される。
