# パシフィコエナジー FSC-FM案件 フォルダ再編

Google Drive の案件フォルダを、承認済みの階層へ組み替えるための移行スクリプトと決定事項。

- 現行: `マイドライブ / 03_新規取得 / パシフィコエナジー`
- 再編後: `マイドライブ / 03_新規取得 / パシフィコエナジー_FSC-FM`
- 構造の調査レポート(図式・問題点・再編案): 2026-07-28 に別途共有

## なぜスクリプトなのか

このセッションで使える Google Drive のツールには、フォルダ作成とコピーはありますが
**移動・改名・削除の操作がありません**。コピーで代替すると原本が残って複製が増え、
今回いちばん解消したい重複をむしろ増やしてしまいます。

そのため移行は Google Apps Script として実装しています。`drive_reorg.gs` を
一度実行すれば、約 40 件のフォルダ移動と約 60 件のファイル移動・改名、
ショートカット生成、空フォルダの片付けまでが通しで終わります。

## 済んでいること (2026-07-28)

新ルートと空フォルダの枠は Drive 上に作成済みです。

- 新ルート `パシフィコエナジー_FSC-FM` — `1e5kwikCOOy7fNIVem3ogEFZGEU1bisw5`
- 第1〜2階層の 26 フォルダ（`00_案件管理` 〜 `90_アーカイブ/2026`、`40_原則別根拠` の原則別 7 フォルダを含む）
- `00_案件管理/README_フォルダ運用ルール`（命名規則を案件内に常設）

既存ファイルは 1 件も動かしていません。**移動・改名・アーカイブは未実行**で、
`drive_reorg.gs` を実行して行います。スクリプトは同名フォルダがあれば作り直さず
再利用するため、作成済みの枠とそのまま噛み合います。

## 実行手順

1. <https://script.google.com> で新規プロジェクトを作成し、`drive_reorg.gs` の内容を貼り付ける
2. `CONFIG.DRY_RUN = true` のまま `main()` を実行する（1件も変更されない）
3. 実行ログで移動先・改名後の名前と「人の判断が必要な項目」を確認する
4. 問題なければ `CONFIG.DRY_RUN = false` にして `main()` を再実行する
5. `40_原則別根拠` のショートカットを作る場合のみ、エディタ左の **サービス** から
   **Drive API (v3)** を追加する（識別子は `Drive`）。追加していない場合は
   ショートカットだけスキップされ、他の処理は完走する

初回実行は数分かかります。114MB / 57MB のファイルも移動のみなので再アップロードは発生しません。

## 設計上の約束

| 方針 | 理由 |
| --- | --- |
| 移動のみ。コピーしない | 実体を常に1か所に保つ |
| 削除しない | 不要物は `90_アーカイブ` へ。空になった旧フォルダをゴミ箱に入れるだけ |
| 2026-07-25 以降に更新されたファイルは改名しない | 第一段階審査(7/27-29)の会期中に編集中のものがあるため。該当分は改名候補をログに出す |
| 判断が割れているファイルは自動で正を決めない | 下記「人が決める必要がある項目」を参照 |
| 旧構造は残す | 外部に共有したリンクが旧パスを指している可能性があるため、1か月ほど置いてから削除する |

## 審査期間についての注意

第一段階審査は 7/27〜29 の会期中です。**審査が終わってから実行することを勧めます。**
審査員が参照しているフォルダを動かすと、共有リンクの階層が変わって混乱を招きます
（ファイル単体のリンクは移動後も有効ですが、フォルダを辿っている場合は影響します）。

審査中でも安全に着手できるのは、次の「人が決める必要がある項目」の 1 と 2 だけです。
これはファイルを動かさず、内容を突き合わせて正を決める作業です。

## 命名規則

移行後はこの規則で運用します。`00_案件管理/README_フォルダ運用ルール` として案件内にも置いてください。

- 基本形 `YYYYMMDD_書類名_v1.0.ext` ── 日付は 8 桁固定
- 版は `v1.0` `v1.1` `v2.0` のみ。`ver.` `rev.` `r0.1` `Rev.0` は使わない
- 確定版は末尾に `_確定` のみ。`_final` `_確定版` `_最終版` の重ね書きは禁止
- 担当者名はファイル名に入れない（`_高橋記入` `_森谷確認用` `_森未来追記` `_In…` は廃止）。
  Drive のコメントと更新履歴に寄せる
- 相手先はフォルダ名でのみ表す。敬称は `様` に統一
- 半角・全角空白は使わずアンダースコア
- スクリーンショットは貼った時点で `YYYYMMDD_対象_内容.png` に改名
- 旧版は同一フォルダに残さず即 `90_アーカイブ/年/` へ。各フォルダ配下に `旧/` を作らない
- 案件名は `パシフィコエナジー`（中黒なし）に統一

## 元に戻したいとき

`CONFIG.DRY_RUN = false` で実行したあとに戻す場合:

- ゴミ箱に入った旧フォルダは Drive のゴミ箱から復元できます（30 日以内）
- 移動したファイルは `90_アーカイブ` を含めすべて残っているので、
  失われるものはありません。手動で元の位置に戻せます
- 改名は元の名前がこのリポジトリの `drive_reorg.gs` の `from:` に記録されています
