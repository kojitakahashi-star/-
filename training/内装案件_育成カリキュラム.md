# 内装案件 育成カリキュラム（営業マネージャー向け）

作成：木材コーディネート担当（内装歴30年の現場目線で）
対象：内装案件の進め方に悩んでいる営業マネージャー
期間：8週間（毎週「課題 → 提出 → フィードバック」を1サイクルで回す）

---

## 0. はじめに：なぜこのカリキュラムが必要か

社内の数字を先に押さえておきます（2026/9/4 朝会メモより）。

- 会社目標から逆算すると、内装案件の **総玉（パイプライン）は約6億円が必要**（成約率35%前提）
- そのための行動目標は **内装案件の商談 毎月60件**
- 現状は「商談がそもそも足りない → 角度を上げる案件もない」状態
- マネージャーに期待されているのは **①商談を増やす ②成約率を上げる ③メンバーが役割どおりに動ける状態をつくる**

内装案件は「木材を売る」仕事ではありません。**設計者・デザイナー・内装施工会社が抱えている『木を使いたいけど面倒なこと』を引き受ける仕事**です。
面倒なこととは、だいたい次の5つに集約されます。

1. **法規**：内装制限・不燃／準不燃の認定、消防の指導
2. **調達**：その樹種・寸法・数量が、その納期で本当に手に入るか
3. **色と質感**：化粧板・クロス・塗装とのトーン合わせ、サンプル
4. **コスト**：VE（減額）で木が真っ先に削られる
5. **ストーリー**：地域材・既存樹・社有林・森林認証（FSC/SGEC）など「語れる理由」

この5つを、自分の言葉で、お客様の前で語れるようになることがゴールです。

## 1. カリキュラム全体像（8週間）

| 週 | テーマ | 身につけること | 主な教材 |
|---|---|---|---|
| **1** | **内装案件の全体像とヒアリング** | 案件フロー・関係者・ヒアリング項目 | 本書／内装木質化資料v3／Sales Agent外報 |
| 2 | 法規の基礎（内装制限・不燃） | 「どこに・何が使えるか」を判断する入口 | 不燃木材ウェビナー資料、国交省資料 |
| 3 | 材料の基礎（無垢・突板・合板・集成材・MDF・古材） | 用途と材料を結びつける | 不燃突板・カラーMDF・古材ウェビナー資料 |
| 4 | 調達と工程（製材→乾燥→加工→不燃処理→製作→納品） | 納期・ロット・リスクを読む | 過去案件フォルダ（上石神井 等） |

| 7 | 商談設計とチャネル開拓（内装施工会社・設計事務所・ゼネコン） | 商談60件/月の作り方 | 船場・鹿島・戸田建設の外報/議事録 |
| 8 | マネジメント（朝会・1on1・外報FBの回し方） | メンバーを動かす仕組み | 朝会メモ、Sales Agent |

各週の進め方：
- **月曜**：課題を渡す（本書の該当週）
- **木曜 12:00**：提出（Notion または Slack スレッドで）
- **金曜**：フィードバック（Good / More / Other の3段で返す。外報FBと同じ型）
- 翌週の課題は、前週のフィードバックを踏まえて調整する

## 2. 今週（第1週）の課題：内装案件の全体像とヒアリング

### 今週のゴール
「内装案件がどう生まれ、どこで木材が決まり、どこで森未来が入れるか」を説明できること。
そして **初回ヒアリングで聞き漏らさない型** を自分で持つこと。

### 課題1：内装案件の流れを1枚に書く（目安 60分）

次の工程を横に並べ、**各工程で「誰が」「何を決めているか」「木材の何が決まるか」「森未来が入れる余地」** を書いてください。

```
企画・構想 → 基本設計 → 実施設計 → 見積・VE → 業者決定（入札/特命）
→ 製作図・承認（サンプル承認含む） → 材料手配・製作 → 施工 → 引渡し
```

登場人物の例（全員を配置すること）：
施主（エンドクライアント）／設計事務所・インテリアデザイナー／内装施工会社（乃村工藝社・丹青社・船場・スペース 等）／ゼネコン／家具・什器メーカー／造作業者／製材所・合板メーカー／不燃処理業者／森未来

> ヒント：名古屋熱田のレストラン案件は「デザインは乃村工藝社、内装は入札で別会社に決定」しています。**デザインを決めた人と、材料を発注する人が違う**——これが内装案件の最大のポイントです。どちらに、いつ、何を当てるかを考えてください。

### 課題2：初回ヒアリングシートを作る（目安 90分）

実際に動いている **「アークテリクス店舗内装_焼杉調達（株式会社アルス）」** の再ヒアリングを想定して、ヒアリングシートを作ってください。最低限、次の6分類で各3問以上。

| 分類 | 例 |
|---|---|
| ① 物件 | 用途（物販店舗）／所在地／階数・規模／新築か改装か／出店数（国内全店展開か） |
| ② 法規 | 内装制限はかかるか（壁・天井どちら？）／求める性能は不燃・準不燃・難燃のどれか／消防・ディベロッパー（SC）の独自基準はあるか |
| ③ 仕様 | 焼杉の焼き具合（炭化の深さ）・色・幅・厚み／貼り方／仕上げ（炭が手につかない処理の要否）／意匠上どこまで本物にこだわるか |
| ④ 数量・納期 | 1店舗あたりの㎡数／店舗数／初回納品希望日／出店スケジュール |
| ⑤ 予算・決定 | 予算感／比較対象（他社・代替材）／誰が最終決定するか（ブランド本国か日本法人か） |
| ⑥ 背景 | なぜ焼杉なのか（ブランドストーリー）／過去に困ったこと／サンプルはいつ・何枚必要か |

**必ず書くこと**：「不燃認定のある焼杉」がないと言われた場合の **代替案を2つ** 準備しておくこと（例：内装制限がかからない部位だけ本物、制限部位は不燃突板＋焼き風仕上げ 等）。代替案を持たずにヒアリングに行くと「探します」で持ち帰るだけになります。

### 課題3：失注案件の振り返り（目安 30分）

**「愛知県オフィス_内装家具（モチノキ検討）／株式会社スペース」** は「VE対象となった（予算と提案タイミングが合わず、モチノキ利用案がなくなった）」で失注しています。

次の3点を、各3行以内で書いてください。
1. VEで木が削られるのは、工程のどの時点で何が起きたからか
2. もし自分が担当なら、**どのタイミングで・誰に・何を** 提案していたか
3. この失注から、チームのルールとして1つ決めるとしたら何か

### 課題4：自チームの数字を逆算する（目安 30分）

「商談60件/月」を、メンバー別・チャネル別（問い合わせ／ウェビナー・セミナー経由／ISメール／既存顧客の深掘り／紹介）に分解してください。
現状の実績との差を出し、**差を埋める打ち手を1つだけ** 選んで理由を書いてください（打ち手を複数並べるのは禁止。1つに絞る練習です）。

### 提出物と期限
- 提出：**木曜 12:00 まで**（Notion の個人ページ、または Slack のスレッドで共有）
- 形式：手書き写真・スライド・箇条書き、何でもOK。きれいさより **自分の言葉で書いてあること** を重視します
- 分からないところは「分からない」と書いてください。それ自体が来週の課題になります

### フィードバックの観点（評価基準）

| 観点 | 合格ライン | よくある落とし穴 |
|---|---|---|
| 全体像 | 「決める人」と「発注する人」が分けて書けている | 施主→森未来の一本線で描いてしまう |
| 法規 | 内装制限の有無を **最初に** 確認する設計になっている | 樹種・色の話から入り、後で不燃NGが判明して振り出し |
| 具体性 | 質問が「はい/いいえ」でなく数字・日付・名前を引き出す形 | 「案件ありますか？」→「今はない」で終わる |
| 代替案 | 持ち帰りでなく、その場で次の選択肢を出せる | 「確認して折り返します」だけ |
| 数字 | 60件を行動量まで落とせている | 目標を書き写しただけで、打ち手が抽象的 |

フィードバックは外報FBと同じく **Good（良かった点）／More（もっと良くなる点）／Other（引き出しを増やすヒント）** の3段で返します。

## 3. 第2週以降の予告（課題の骨子）

- **第2週 法規**：自分が担当した／担当する物件1件を選び、「内装制限がかかるか」を用途・規模・部位から判定してみる。判定に迷った点を3つ挙げる。
  - 補足：2025年8月に「建築基準法施行令の一部を改正する政令」が閣議決定され、内装制限・排煙・防煙壁等の防火規制が木材利用促進の方向で見直されています。告示の詳細と施行日は必ず原文で確認すること。官庁施設でも、内装制限の対象外部分（腰壁、エントランス天井など）で不燃処理なしの木材を使う手法が2024年に示されています。
- **第3週 材料**：無垢・突板・合板・集成材・MDF・古材について「価格帯／不燃化の方法／得意な用途／苦手な用途」を表にまとめる。
- **第4週 調達**：過去の完了案件フォルダを1件読み込み、工程表と「一番ヒヤッとした所」を抜き出す。
- **第5週 VE**：減額要請が来た時の「木を残す3段階の代替案」（グレード・部位・材料の置き換え）を作る。
- **第6週 ストーリー**：地域材・既存樹・社有林・認証材の事例から、1件を選んで2分のトークにする。
- **第7週 商談設計**：内装施工会社1社を選び、外報（アポ背景・仮説・ゴール）を書いて実際にアポを取る。
- **第8週 マネジメント**：メンバー1名の外報にFBを書き、朝会で使う「行動KPIシート」を作る。

## 4. 30年やってきた人間からの一言

内装は「最後に決まって、最初に削られる」世界です。
だからこそ、**早く入って、法規とコストの不安を先に消し、サンプルで決めてもらう**。これだけで勝率は大きく変わります。
今週は完璧を目指さなくていいので、まず書いて出してください。書いたものがあれば、いくらでも一緒に磨けます。
